# Getting help

- **Something does not work:** read the troubleshooting table in the [README](README.md#troubleshooting), then
  [open a bug report](https://github.com/msx752/DebugViaMcp/issues/new?template=bug_report.yml) with the versions, the steps
  and the logs.
- **A question or an idea:** use [Discussions](https://github.com/msx752/DebugViaMcp/discussions).
- **A feature you miss:** [open a feature request](https://github.com/msx752/DebugViaMcp/issues/new?template=feature_request.yml).
- **A security problem:** do not open an issue; see [SECURITY.md](SECURITY.md).

This is a free project maintained in spare time, so answers are not instant. A clear report with logs is answered faster.
